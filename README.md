# ExoMind

Official repository for **ExoMind: Democratizing Scientific Intelligence via Extended-Mind-Inspired Agentic System**.

> **Release status:** This repository currently hosts the official ExoMind project page. The technical report, model weights, data, and training and inference code are forthcoming and will be released here or linked from this repository when available.

## Project page

https://ai4sgi.github.io/ExoMind/

## Overview

ExoMind is an extended-mind-inspired agentic system for scientific reasoning and research. It combines systematic data engineering, a scientific interaction framework, and a progressive training strategy to improve scientific intelligence with a compact model and a focused training budget.
